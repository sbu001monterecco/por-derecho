Current operating rule. GitHub is the active continuity backend while authenticated GitLab remains blocked. Public GitLab Pages is a comparator, not a source-code substitute. Outage-period GitHub improvements must not be force-reset away when GitLab returns.

THE RECOVERY PIPELINE

1 · Trace

Resolve route, person, proceeding, source, event, asset and decision identities before drawing conclusions.

2 · Preserve

Freeze exact SHAs, source hashes, public-safe derivatives and the current rendered site without publishing private evidence.

3 · Protect

Keep allegation, source statement, procedural act, finding and inference separate; retain contrary evidence and privacy boundaries.

4 · Recover

Admit only material whose provenance is exact or whose GitHub-native replacement is explicitly classified as functional equivalence.

5 · Reconcile

When GitLab authentication returns, compare exact objects against then-current GitHub and integrate additively through normal review gates.
