Concurso 36/2012: reconstruct the whole procedural chain without pretending the docket is complete

The historical workbook contains more than six hundred indexed rows and is useful as a discovery spine. It is not self-verifying evidence. This page makes the source-promotion rule, the remaining documentary gaps and the balanced decision matrix public so later analysis can be checked against the same denominator.

Primary docket still incomplete · public completeness claims gated

Publication boundary. “Not located” means absent from the controlled corpus only. It does not establish nonexistence, loss, suppression or alteration. A located decision does not by itself prove service, finality, implementation or accounting effect. This is a continuity and evidence-status page, not a merits judgment and not a complete dossier on any Judge or LAJ.

The promotion rule

WORKBOOK ROW → LOCATE UNDERLYING SOURCE → VERIFY DATE / TYPE / SIGNATORY → EXTRACT OPERATIVE PART → RECONSTRUCT NOTIFICATION / APPEAL → PROMOTE TO MASTER REGISTER

Where a signed primary act has not been recovered, the narrower source status must remain visible: DISCOVERY WORKBOOK, REFERENCED BY PRIMARY ACT or OFFICIAL LATER REFERENCE. A derivative reference is not silently upgraded into a signed primary act.

Procedural nodes stay separate:
filing → receipt → opposition → decision → service → clarification/reconsideration → appeal → appellate decision → finality → implementation/accounting
