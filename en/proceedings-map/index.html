Unitary digest · bidirectional procedural map

How the proceedings connect

The record is not one proceeding. It is a set of legally distinct judicial, prosecutorial, insolvency, administrative, tax, regulatory, professional and public-funds tracks that can intersect around the same chronology, evidence and assets. This map is designed to make those intersections understandable without erasing their legal boundaries.

How to read the lines. A direct procedural relationship is shown only from an explicit canonical parent/link/review field. A context bridge is a navigation lens such as the same recorded track, connection or geography. Context does not mean joinder, coordination, knowledge, wrongdoing or liability.

A map of maps, not a spider web

Start anywhere. Read by procedural track, move approximately through time, or choose one proceeding and trace it both forwards and backwards. The trace view inverts explicit parent/link data so a child can lead back to its origin and a parent can reveal its recorded descendants.

The canonical node list remains archive/PROCEEDINGS_MASTER_REGISTER.csv. This page is a controlled public projection of that same source, not a second case register.

The map is navigation, not the evidence itself

A material proposition still needs the underlying filing, decision, institutional original, registered receipt, ACTA, communication or other appropriate source. Open reference gaps remain visible because uncertainty is part of the procedural record. The purpose of this map is to help a reader discover the correct next node and understand why it may matter.
