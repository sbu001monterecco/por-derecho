Truth Machine: recursive, source-bound review

The machine does not decide who is lying. It makes source changes, contextual omissions, generalisations, capacity shifts and unresolved proof visible, then reopens dependent analysis when the record changes.

Boundary. Automated stages are integrity checks and triage. Merits conclusions require source/context/contrary-evidence review. Repetition, another host or another AI summary is not independent corroboration.

1 · Pin

Exact source path + reviewed Git blob.

2 · Triage

Deterministic candidate cues; no truth score.

3 · Restore

Original context, later use and invited inference.

4 · Adversarial test

Contrary evidence + strongest lawful alternative.

5 · Dependencies

Actor, capacity, time, proceeding and causation.

6 · Recurse

Changed source → reopen → changed/no-change decision.
