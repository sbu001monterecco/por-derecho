Truth Machine: document, language, context and network

A recursive forensic architecture that treats each sentence as a testable proposition inside its source, context, actor, capacity, chronology, proceeding, financial flow and evidential lineage.

Data-driven interface · refreshes every 60 seconds · methodology date: 2026-09-25

Not a lie detector. Linguistic features and network patterns generate review questions. Falsity, intent and liability require sources, context, contrary evidence and human review.
