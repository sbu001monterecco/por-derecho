How to read the record

Status before conclusion.

Every serious reader should be able to tell whether a proposition is a source fact, an attributed allegation, analysis, an official procedural status or an open evidential question.

Documented fact

A proposition supported by an identified source. The source proves only what it actually records.

Attributed allegation / analysis

A claim or interpretation advanced by Gil Marer or another identified source; it is not presented as an adjudicated finding.

Official status / open question

Procedural state is separated from merits. Missing evidence, contrary evidence and decisive tests remain visible.
