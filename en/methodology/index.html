THE OPERATING SYSTEM

The public operating loop

Every material cycle preserves its predecessor, current state, decisions, unresolved gaps and verification receipts. A later step cannot silently upgrade an earlier one.

  1. Observe

    Retrieve before reasoning.

    Resolve current sources, repository state, identities, proceedings and governing rules. Memory is a retrieval aid, never evidential authority.

    What can stop this stage?

    Stop if the source universe, authority, identity or current host state is unresolved.

  2. Manifest

    Make the universe explicit.

    Record what was examined, hashes, provenance, source classes, exclusions, current heads and known missing material.

    What can stop this stage?

    Stop if the denominator or provenance cannot be stated honestly.

  3. Compare

    Compare versions, evidence and projections.

    Source against source; current against predecessor; GitHub against GitLab; English against Spanish; assertion against contrary record.

    What can stop this stage?

    Stop on unexplained divergence, stale baselines or incomplete comparison coverage.

  4. Classify

    Do not collapse unlike things.

    Keep documented fact, attributed allegation, inference, hypothesis, legal characterisation, open question, private-only and corrected/superseded states separate.

    What can stop this stage?

    Stop if language exceeds the evidence class or privacy/publication state.

  5. Traverse dependencies

    Ask what else changes if this changes.

    Recursively reopen dependent actors, chronologies, proceedings, hypotheses, institutional communications, translations, pages and releases.

    What can stop this stage?

    Stop cycles with a visited set; keep recursion bounded and every branch attributable.

  6. Adversarial review

    Try to prove ourselves wrong.

    Seek the strongest contrary and exculpatory evidence, the best lawful alternative explanation and the finite discriminator between competing accounts.

    What can stop this stage?

    Stop if material contrary evidence or a coherent innocent explanation has not been tested.

  7. Reconcile

    Create one controlled current state.

    Resolve conflicts, preserve provenance, record typed supersession and integrate only through one scoped writer lane.

    What can stop this stage?

    Stop on path collision, ambiguous ownership, privacy conflict or silent overwrite risk.

  8. Exact-head verify

    Test the thing that would actually be merged.

    Verify exact SHA, source bytes and the applicable identity, privacy, provenance, bilingual, build and publication gates.

    What can stop this stage?

    Stop if the tested head differs from the merge candidate or any required gate is red.

  9. Deploy if applicable

    Merge is not publication.

    Only an authorised release path may deploy an approved projection. A green build or merge never proves the public site changed.

    What can stop this stage?

    Stop without publication authority, an approved projection or an exact tested release artifact.

  10. Live readback

    Verify what the public actually receives.

    Read affected routes from the public edge and compare expected and observed bytes, markers and state.

    What can stop this stage?

    Stop if live bytes or state cannot be proved; never infer deployment from CI.

  11. New envelope

    Record the result—and recurse.

    Emit the next state envelope with predecessor, heads, decisions, unresolved gaps and verification receipts; recurse only when a defined trigger remains.

    What can stop this stage?

    Close only on defined terminal conditions; otherwise create a finite next task or explicit blocker.

↺New evidence, correction, host change or failed check reopens the loop
The loop is recursive. The constitution is not.

The system may improve retrieval, schemas, prompts, ranking, validators and workflow. It may not improve away source integrity, contrary evidence, privacy, actor-specific attribution, publication ceilings or authority controls.

TWO-KEY ADVANCEMENT

Two independent keys

Strategic value never substitutes for evidential maturity.

Key A — Outcome

What lawful next step best advances recovery, correction, preservation or accountability from the evidence actually held?

Key B — Truth / falsification

What would disprove or materially qualify the proposition? What contrary material and strongest lawful alternative exist?

A material step advances only if it survives both keys. Strategic importance can raise verification priority; it cannot raise evidential maturity.

EPISTEMIC FIREWALL

What one thing does not mean

These non-equivalences are safeguards against semantic escalation.

A filing was registeredIts contents are true

A person could have knownThey actually knew
A person benefitedThey intended or joined wrongdoing

FALSIFICATION

Adversarial by design

A preferred theory is not protected from contrary evidence. Material evidence that weakens it is a high-value integrity event.

Support

What independent and primary material supports the proposition?

Contrary / exculpatory record

What weakens, limits, contradicts or innocently explains it?

Discriminator: what finite evidence would distinguish the competing explanations?

Transparency boundary

The methodology is public. Private evidence is not. We publish rules, classifications, correction logic, checks and public-safe provenance; we do not expose privileged communications, private identifiers, credentials or protected source locators merely in the name of transparency.

CORRECTION

How we correct ourselves

ORIGINAL PROPOSITION→NEW EVIDENCE OR ERROR→CORRECTION OBJECT→TYPED SUPERSESSION→DEPENDENCY REVIEW→AFFECTED PROJECTIONS REOPENED→NEW RELEASE IF APPROVED→LIVE READBACK

We preserve the old proposition as provenance and stop treating it as current truth; dependants are reopened rather than silently inheriting the correction.

CLOSURE

When recursion stops

PROVEDDISPROVEDNOT_APPLICABLECLOSED_NO_ACTIONOPEN_FINITE_GAPSOURCE_BLOCKEDROUTE_PENDINGHUMAN_REVIEW_REQUIRED

An open node without a finite child task, explicit gap or terminal reason is invalid. Recursion is bounded; repetition without information gain is not improvement.

SELF-IMPROVEMENT WITH SAFEGUARDS

How the method itself improves

DETECT FAILURE OR OPPORTUNITY→PROPOSE CHANGE→GOLDEN CORPUS TEST→SHADOW RUN→SAFEGUARD REGRESSION CHECK→HUMAN REVIEW→MERGE→MONITOR→POST MORTEM

A change that makes the case look stronger by suppressing contrary evidence, weakening provenance, widening a private/public boundary or bypassing live verification is a regression—not an improvement.
