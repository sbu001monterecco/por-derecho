RESOLUTION RULES

The ID resolves identity; it does not attribute responsibility.

Never reused.

An ID remains attached to the same identity even when the display name, office, procedural status or corporate relationship changes.

An alias is not a new actor.

Initials, unaccented variants and known errors point to the canonical record while preserving the wording found in the source.

Person, company and perimeter remain separate.

A natural person, legal entity and analytical structure never share an ID and cannot substitute for each other.

Identity does not transfer intent.

A shared entity, representation, document or perimeter does not transfer knowledge, intention, control or criminal responsibility.

Uncertainty remains visible.

A perimeter label or unresolved legal variant retains its ID and warning until sufficient source material supports a correction to the name or classification.

Action is not accusation.

An ID appearing in a preservation or production request means a documentary control is open; it does not mean responsibility has been adjudicated.

Governance for future threads. Before creating a node or attributing an act, identity must be resolved against this registry. New evidence updates the same ID; it should not create a duplicate narrative or a second person because of a naming variant. Every correction must preserve the earlier value as an alias, legacy key or non-equivalence reference where needed to retain traceability.
