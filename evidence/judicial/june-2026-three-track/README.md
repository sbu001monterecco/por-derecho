# June 2026 Las Palmas three-track record — dual-version archive

Control date: 21 September 2026

This directory implements a two-layer preservation rule for **Ref21, Ref22 and Ref24**.

## Version 1 — FROZEN

The frozen layer preserves the controlled source-time wording page by page. It is not rewritten to make the case stronger or more coherent. Only direct personal identifiers/contact details are removed from the public-safe transcription. Source errors, contradictions, labels, dates, amounts and internal qualifications remain visible.

A frozen transcript proves what the controlled source says. It does **not** by itself prove that the exact bytes were electronically ingested, sent to Fiscalía, admitted or examined unless a separate receipt or certified court record proves that state.

## Version 2 — DYNAMIC

The dynamic layer is a living forensic/legal reader. It may correct source attribution and procedural status, distinguish allegation/testimony/corroboration/authority fact, add later developments, interlink actors/events/proceedings/evidence, record contrary evidence and improve navigation.

The dynamic layer **never overwrites the frozen source**.
