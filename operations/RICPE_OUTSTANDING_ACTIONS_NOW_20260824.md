## Operating rule

- A pending document is not proof of irregularity.
- A pending document must not disappear because the issue is fragmented across authorities, websites or instruments.
- Each unresolved item must have: issue, competent source/body, document required, next action, status, and evidential boundary.
- When verified evidence closes an item, update the public status promptly and with equivalent prominence.
