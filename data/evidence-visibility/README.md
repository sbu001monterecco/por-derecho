# Evidence visibility packages

This directory contains machine-readable packages governed by `PD-EVIS-20260904-01`.

Every package must declare, for every evidence item:

- native/original source and integrity state;
- searchable text/OCR and translation state;
- source-derived visual evidence state;
- redaction and sensitivity state;
- actor, entity, proceeding, event and page relationships;
- publication and live-readback state;
- exact open gaps, next action and owner role.

A package may truthfully remain partial. It may not claim visual completeness while a source or image set is pending or blocked.
