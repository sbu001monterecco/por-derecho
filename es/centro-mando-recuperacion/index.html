Centro de Mando de Recuperación

Una superficie operativa para trazar lo que existe, preservarlo, proteger sus límites probatorios, recuperar sólo lo acreditable y reconciliar GitLab únicamente cuando vuelva el estado fuente exacto.

Regla operativa actual. GitHub es el backend activo de continuidad mientras el acceso autenticado a GitLab sigue bloqueado. GitLab Pages público es un comparador, no un sustituto del código fuente. Las mejoras realizadas en GitHub durante la caída no se eliminarán mediante un reset forzado cuando vuelva GitLab.

LA CADENA DE RECUPERACIÓN

1 · Trazar

Resolver ruta, persona, procedimiento, fuente, evento, activo y decisión antes de formular conclusiones.

2 · Preservar

Congelar SHA exactos, hashes de fuente, derivados públicos seguros y la web renderizada sin publicar prueba privada.

3 · Proteger

Separar alegación, declaración de fuente, acto procesal, hallazgo e inferencia; conservar prueba contraria y límites de privacidad.

4 · Recuperar

Admitir sólo material con procedencia exacta o sustituciones nativas de GitHub expresamente clasificadas como equivalencia funcional.

5 · Reconciliar

Cuando vuelva GitLab autenticado, comparar objetos exactos con el GitHub vigente e integrar de forma aditiva mediante los controles normales.
