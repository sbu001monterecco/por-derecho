Una identidad. Un ID inmutable.

Este registro asigna una referencia interna estable a cada persona, organización, estructura analítica, institución y procedimiento admitido en el corpus canónico actual. Los alias, iniciales, errores ortográficos y variantes lingüísticas se resuelven hacia la misma identidad; no crean actores paralelos.

Límite de cobertura. El registro está completo para el registro canónico de actores y el mapa de convergencia v2 actuales. La revisión retrospectiva de todos los correos, anexos, escritos y materiales históricos sigue abierta. Una mención todavía no resuelta no se incorpora por semejanza nominal ni se conecta automáticamente a una identidad existente.
Límite de significado. Un ID inmutable resuelve una referencia interna. No certifica por sí solo la denominación jurídica exacta, forma social, representación, cargo, relación, conocimiento, control o responsabilidad. Los registros sujetos a verificación o con correspondencia no resuelta se identifican ahora expresamente y pueden filtrarse.

REGLAS DE RESOLUCIÓN

El ID resuelve identidad; no atribuye responsabilidad.

No se reutiliza.

Un ID permanece unido a la misma identidad aunque cambien el nombre visible, el cargo, el estado procesal o la relación societaria.

Alias no equivale a actor nuevo.

Iniciales, variantes sin tildes y errores conocidos apuntan al registro canónico y conservan la trazabilidad del término utilizado.

Persona, sociedad y perímetro son distintos.

Una persona física, una entidad jurídica y una estructura analítica nunca comparten ID ni se sustituyen entre sí.

Identidad no transfiere dolo.

Compartir una entidad, representación, documento o perímetro no transmite conocimiento, intención, control ni responsabilidad penal.

La incertidumbre permanece visible.

Una etiqueta de perímetro o variante jurídica no resuelta conserva su ID y su advertencia hasta que una fuente suficiente permita corregir el nombre o la clasificación.

Acción no equivale a acusación.

Que un ID figure en una solicitud de preservación o producción significa que existe un control documental abierto; no que se haya declarado responsabilidad.

Gobernanza para futuros hilos. Antes de crear un nodo o atribuir un acto, debe resolverse la identidad contra este registro. La nueva prueba actualiza el mismo ID; no debe generar una narrativa duplicada o una segunda persona por una variante nominal. Toda corrección debe preservar el valor anterior como alias, clave heredada o referencia de no equivalencia cuando sea necesario para mantener trazabilidad.
