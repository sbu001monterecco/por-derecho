IA · TRANSPARENCIA · PRIVACIDAD DESDE EL DISEÑO

Preguntar al expediente sin construir un perfil del visitante.

El asistente es un sistema de inteligencia artificial. Responde a preguntas sobre las páginas públicas de Project Sun Rock / Por Derecho mediante texto o audio. No sustituye asesoramiento profesional, una autoridad, el expediente oficial ni un canal protegido de denuncias.

Sin historial persistente

Project Sun Rock no conserva en su almacén de analítica la pregunta, la respuesta ni la transcripción.

Audio transitorio

El audio se utiliza para transcribir la pregunta y no se guarda como archivo por Project Sun Rock.

Analítica separada

Es opcional y funciona sin almacenar contenido de la conversación ni identificadores persistentes.

Tratamiento previsto

ResponsableGil Marer, como responsable editorial de este sitio, salvo que una actividad separada identifique expresamente a otro responsable. Contacto y derechos: consulte el aviso completo de privacidad.
TextoSe procesa de forma transitoria para recuperar páginas públicas relevantes y generar la respuesta. No se guarda como historial de conversación por Project Sun Rock.
AudioSe transmite al backend para transcripción. No se realiza identificación de hablante, reconocimiento de identidad ni creación de huellas de voz. El audio original no se conserva por Project Sun Rock después de la solicitud.
Proveedor IAEl backend está preparado para usar la API de OpenAI. Las solicitudes de respuesta usan store:false. OpenAI indica que los datos de la API no se utilizan para entrenar sus modelos por defecto; la retención técnica o de seguridad depende de la configuración de la cuenta. La residencia y retención cero en Europa requieren una configuración/proyecto elegible.
AlojamientoEl backend está diseñado para ejecutarse como función de Netlify en la región Frankfurt (UE). Los proveedores de alojamiento pueden generar registros técnicos propios de seguridad conforme a sus términos.
Base jurídica de la funciónEl diseño parte del interés legítimo en responder a una solicitud iniciada voluntariamente por el visitante con un tratamiento mínimo, transitorio y esperado. Antes del despliegue productivo debe mantenerse documentada la ponderación correspondiente y reevaluarse la base si se añaden cuentas, historial, identificación u otras finalidades.
Analítica opcionalSolo se activa mediante una casilla separada. Se agregan por día: idioma, texto/audio, tema, página, estado de la respuesta, número de fuentes, categoría amplia de interés elegida voluntariamente y país aproximado. No se almacenan pregunta, transcripción, respuesta, IP ni ID persistente. La base prevista para esta finalidad es el consentimiento, que puede denegarse sin perder el chatbot.
PerfiladoNo se crea un perfil individual, no se sigue al visitante entre sesiones y no se adoptan decisiones con efectos jurídicos o similares sobre él.
Datos sensiblesNo se solicitan. No envíe información confidencial, privilegiada, categorías especiales de datos, datos sobre menores ni información personal innecesaria. Si necesita comunicar una posible infracción, utilice un canal oficial o protegido.
Importante sobre proveedores. Que Project Sun Rock no conserve el contenido no significa automáticamente que ningún proveedor técnico pueda aplicar retenciones de seguridad. Antes de activar el servicio deben verificarse el acuerdo de tratamiento, la configuración de la cuenta de IA, las transferencias y, cuando se requiera, la opción europea de residencia/retención cero.

Qué información puede resultar útil sin identificar a una persona

La analítica agregada permite saber qué temas generan más preguntas, si predominan texto o voz, qué idiomas se utilizan, desde qué páginas se abre el asistente, qué proporción de respuestas carece de fuentes suficientes y qué categorías amplias de visitantes deciden declarar voluntariamente. El objetivo es mejorar contenido y navegación, no averiguar quién es una persona concreta.
