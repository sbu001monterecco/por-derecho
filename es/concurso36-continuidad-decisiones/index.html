Concurso 36/2012: reconstruir toda la cadena procesal sin presentar el expediente como completo

El libro histórico contiene más de seiscientas filas indexadas y sirve como eje de descubrimiento. No es prueba autoverificable. Esta página hace públicas la regla de promoción de fuentes, las lagunas documentales restantes y la matriz equilibrada de resoluciones para que el análisis posterior pueda contrastarse contra el mismo denominador.

Expediente primario aún incompleto · afirmaciones públicas de completitud sujetas a control

Límite de publicación. “No localizado” significa únicamente ausente del corpus controlado. No acredita inexistencia, pérdida, supresión ni alteración. Una resolución localizada no acredita por sí sola notificación, firmeza, ejecución ni efecto contable. Esta es una página de continuidad y estado probatorio, no una decisión sobre el fondo ni un dossier completo sobre ningún Juez o LAJ.

Regla de promoción

FILA DEL WORKBOOK → LOCALIZAR FUENTE SUBYACENTE → VERIFICAR FECHA / TIPO / FIRMANTE → EXTRAER PARTE DISPOSITIVA → RECONSTRUIR NOTIFICACIÓN / RECURSO → PROMOVER AL REGISTRO MAESTRO

Cuando no se haya recuperado el acto primario firmado, debe mantenerse visible la clasificación más limitada: DISCOVERY WORKBOOK, REFERENCED BY PRIMARY ACT u OFFICIAL LATER REFERENCE. Una referencia derivada no se eleva silenciosamente a acto primario firmado.

Los nodos procesales permanecen separados:
escrito → recepción → oposición → resolución → notificación → aclaración/reposición → recurso → resolución de recurso → firmeza → ejecución/contabilidad
