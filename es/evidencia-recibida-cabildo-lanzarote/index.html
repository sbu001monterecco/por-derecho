3671/2022 · proceso de todas las unidades

La Comunidad solicitó incorporar el perímetro alojativo histórico completo. El Cabildo exigió autoridad específica para el trámite, identificación de unidades/fincas, escrituras de unidades propias y título habilitante expedido por los propietarios de las restantes.

Yaiza emitió después informe definitivo desfavorable de compatibilidad para la configuración propuesta de una estrella / 220 unidades / 660 plazas. No se ha localizado aún en el corpus de seis ZIP una resolución posterior definitiva sobre el fondo.

2984/2023 · HNT / escisión

El material de febrero de 2023 solicitó MYND Yaiza como cuatro estrellas, 220 unidades / 660 plazas. El Cabildo hizo constar que la situación existente seguía siendo una estrella, 159 unidades / 477 plazas y la Comunidad como titular de explotación, y requirió título suficiente de propiedad más clasificación provisional de cuatro estrellas si se mantenía esa vía.

Estado de publicación de visores PDF

El objetivo de publicación es el documento completo apropiado, buscable y visible en página. Los ZIP nativos permanecen privados porque el corpus incluye números de identidad, firmas, domicilios, metadatos de notificación y otros datos personales.

Estado actual: custodia de fuente e integridad hash completas; revisión documental de los PDF públicos en curso. Un nombre de archivo que contenga «redacted», «censurado» o equivalente solo identifica un candidato y no se considera seguro sin verificación visual. La interfaz de escritura GitHub conectada disponible en este hilo no expone una acción de subida binaria desde archivo montado para este corpus de 190 binarios, por lo que ningún visor se etiqueta falsamente como activo antes de que los bytes PDF revisados existan realmente en GitHub.

Control máquina: estado de publicación PDF. Bloqueo de continuidad: el trabajo GitHub de la incidencia, incluido cada PDF/visor que llegue a estar activo, deberá reconciliarse de forma aditiva con el main canónico de GitLab proyecto 86151898 una vez restablecido el acceso.

Límite de titularidad y recuperación

Los expedientes turísticos acreditan qué se solicitó, aportó, comprobó, notificó y registró. No prueban por sí solos la propiedad actual de cada finca. Las fincas 8584 y 8588 son ejemplos dentro del perímetro de recuperación más amplio, no su denominador; se necesita evidencia registral actual antes de afirmar una posición registral vigente en 2026.
