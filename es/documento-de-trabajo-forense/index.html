Abrir el lector forense

Los archivos privados permanecen en su dispositivo. El lector público muestra un ejemplo ficticio. Cargue un expediente JSON conservado privadamente para trabajar con pruebas reales. No sube archivos ni guarda automáticamente en GitHub, Drive o GitLab. Exporte el JSON antes de cerrar.

Primero, la fuente

La fuente no se modifica. Seleccione palabras o un párrafo, capture el pasaje, añada una anotación y vincúlela a pruebas identificadas. Los colores son categorías de revisión, no declaraciones de falsedad ni responsabilidad penal. Consulte la cobertura y los límites de cada expediente.
