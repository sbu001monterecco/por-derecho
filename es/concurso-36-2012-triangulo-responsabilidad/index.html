Método de continuidad y atribución

Para cada conexión se exige: fuente → fecha → actor/capacidad → acto u omisión identificable → conocimiento demostrable → deber/poder aplicable → respuesta → efecto → explicación lícita alternativa → estado procesal. Un enlace sirve para encontrar y comparar; no demuestra por sí mismo el contenido de la flecha.

Estados obligatorios: hecho primario verificado · identidad/relación procesal verificada · posición de parte · inferencia analítica · contexto · referencia abierta. Una nueva prueba debe actualizar el nodo, sus aristas, las páginas relacionadas, la búsqueda, el registro maestro o su overlay y el handover en la misma unidad de cambio.
