## PASS 4 — Reconstruct evidence before each actor

Create the **Evidence Before Actor Matrix**.

For every disputed proposition and every material contrary document, determine separately whether it was before:

- the Administrador Concursal;
- the Ministerio Fiscal representative;
- the first-instance court/judge;
- the Audiencia Provincial on appeal;
- or another relevant institution.

Record:

| Field | Required content |
|---|---|
| Proposition ID | Baseline proposition or allegation tested |
| Contrary/supporting source | Exact title, date and source ID |
| Actor | AC / Fiscal / Judge / AP / other |
| Transmission route | Email, filing, LexNET, service, annex, hearing, meeting, report incorporation, registry or other |
| Transmission date | Exact date or qualified range |
| Proof | Header, receipt, filing stamp, docket, order, quoted acknowledgment or other bridge |
| Scope | Whole document, extract, attachment, oral summary or reference only |
| Actor response | Acknowledged, disputed, used, omitted, not shown |
| Knowledge grade | One of the four mandatory grades below |
| Limitation | What remains unproved |

Apply exactly these grades:

1. **PROVED BEFORE ACTOR** — a reliable filing, service, receipt, acknowledgment, use or other transmission bridge proves the material reached the actor or the relevant adjudicative record.
2. **STRONG TRANSMISSION INFERENCE** — multiple reliable facts strongly indicate transmission, but direct proof of receipt/review remains incomplete.
3. **INSTITUTIONALLY AVAILABLE ONLY** — the material was somewhere in an institutional file or related source system, but no sufficient bridge proves it was before or reviewed by the named individual.
4. **NOT YET PROVED** — present evidence does not establish the actor-specific transmission or knowledge proposition.

Never upgrade institutional availability into personal knowledge. Never state deliberate falsehood, conscious omission, prevaricación, procedural fraud, concealment or criminal instrumentalisation beyond the grade supported by this matrix.

- publication/defamation risk;
- and overall confidence.

Then assign one of six actions in a **Current Page Strengthening Register**:

1. **RETAIN** — current formulation remains accurate, proportionate and well sourced.
2. **STRENGTHEN** — new primary evidence permits a firmer or more precise formulation.
3. **NARROW** — the core point remains valid but current wording exceeds the proved source or knowledge route.
4. **RELOCATE** — proposition is relevant but belongs in a specialist evidence page, chronology, allegation notebook or private register rather than the main narrative.
5. **CORRECT** — current wording contains a factual, procedural, attribution, translation or source error.
6. **REMOVE** — proposition is unsupported, duplicative, superseded or creates a materially misleading implication that cannot be cured by narrower wording.

For every action record:

- current ES/EN text;
- proposed ES/EN text;
- reason;
- supporting sources;
- adverse sources;
- actor-knowledge grade;
- affected pages;
- repository files requiring propagation;
- and whether publication must wait for another source.

“Strengthen” does not mean adding adjectives. It means making the proposition harder to rebut through exact dates, documents, attribution, causal analysis and procedural status.
