This is **not** authority to send an email or publish a website change.

Future threads must distinguish:

- **RECOMMENDED** — strategic suggestion preserved here;
- **PREPARED** — draft/design exists but is not implemented;
- **IMPLEMENTED** — repository/site/email action actually occurred;
- **VERIFIED** — implementation was independently read back / deployed / sent-copy checked as appropriate;
- **SUPERSEDED** — later evidence or strategy replaced the item.

Do not silently convert a recommendation into completed project state.

## Cross-cutting recommendation — exposure metrics

**Status: ACTIVE PRINCIPLE.**

Do not measure success by number of recipients, CC count or presumed opens.

Measure observable outcomes:

- verified delivery;
- acknowledgment;
- ticket/reference created;
- internal routing;
- evidence incorporated into a file;
- request for more evidence;
- substantive media engagement;
- right-of-reply engagement;
- formal institutional response;
- correct specialist route identified;
- bounce/dead channel;
- no response yet.

Preserve `RECEIVED ≠ EXAMINED ≠ VERIFIED ≠ DECIDED`.
