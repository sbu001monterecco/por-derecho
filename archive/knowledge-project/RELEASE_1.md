# Knowledge Project — Release 1

Release 1 establishes the bilingual public transparency and research-continuity layer for the Knowledge Project.

## Included

- Spanish `/es/proyecto-conocimiento/`
- English `/en/knowledge-project/`
- bilingual research-continuity pages
- public-safe `archive/intelligence/` handover beginning with `START_HERE_CHATGPT.md`
- preliminary corpus/token range clearly labelled as an estimate
- explicit disclosure that the project relies predominantly on ChatGPT and has not developed its own AI foundation model
- evidence-first methodology: source → proposition → event → decision → consequence
- 100M-token figure framed as a planning ceiling, with 10M / 25M / 50M gates
- separation between Fundación Por Derecho public-interest activity and Havidia LLC's intended US commercial pathway
- **Reason to Believe / Razón para creer** integrated as a Foundation-associated publishing and educational project while publication rights, royalties, translation, audio, film and other commercial rights remain separately governed unless formally documented otherwise
- an upcoming-book card in the Por Derecho homepage section
- mobile navigation and canonical/hreflang metadata aligned with the existing bilingual site pattern
- no claim that Havidia owns unassigned IP or has developed proprietary AI

## Continuity pack

The public-safe handover preserves reusable architecture and decisions rather than private source material. It includes the integrated thread handover, evidence/depository schema, corpus/token audit, 90-day/12-month programme, book/Foundation/Havidia architecture and a deletion/continuity gate. Privileged, private, restricted and unreviewed source material remains outside public GitHub and must be retrieved from its lawful source system when needed.

## Publication discipline

Release 1 intentionally does not publish automated guilt scores, private email, privileged material, unreviewed allegations, or a claim that the preliminary corpus census is final. A book purchase and a donation to Fundación Por Derecho are distinct transactions.
