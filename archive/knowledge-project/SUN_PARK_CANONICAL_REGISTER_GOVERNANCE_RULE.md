# Canonical actor-register governance rule

The canonical actor register is append/refine/supersede, not free-edit.

A change to a locked name, relationship or minimum date requires:

1. identified source;
2. proposition classification;
3. comparison with the controlling source;
4. supersession-log entry;
5. synchronized update to the machine index and shared front-end component;
6. review of all dependent public surfaces.

No thread may silently replace a locked fact from memory, a later summary or an unverified spelling.
