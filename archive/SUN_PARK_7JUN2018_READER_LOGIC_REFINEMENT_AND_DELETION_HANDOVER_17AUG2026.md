## 3. Four clocks

The public reader should be able to follow four clocks independently.

### A. Legal / title clock

`Concurso 36/2012 → liquidation / challenges / suspension / adjudication → deed / registration / later title position`

### B. Physical / operational clock

`operating hotel → precursor access / inspection / measurement → 7-Jun practical-control shift → exclusion/disruption → works/preparation → successor operation`

### C. Commercial / financial clock

`Sun Park → refurbishment/redevelopment concepts → Lava Verde → Club Sei / Meeting Point → RICPE project/investment → HNT / MYND → later finance/support`

### D. Institutional / knowledge clock

`Community / AC / court / Fiscalía / CNMV / tax-RIC / tourism-planning / regional-incentive-FEDER actors → what each received, when, and what each did`

**Control:** receipt, possession of information, examination, knowledge, duty, decision and responsibility are separate propositions. Do not infer one from another.

## 4. Parallel lives and converging pressure tracks are different concepts

Future site work must keep these analytically separate.

### Parallel lives — what was the same physical/economic hotel being treated as?

1. **Insolvency asset** — LPB property/rights within Concurso 36/2012.
2. **Mixed-ownership operating hotel** — one economic hospitality platform across LPB, Matkator, other owners, common infrastructure and operating/community rights.
3. **Practically controlled redevelopment site** — access, measuring, security, project preparation and practical control requiring act/date/authority reconciliation.
4. **Commercial hotel project** — later Lava Verde / Club Sei / operator-facing identity.
5. **Investment proposition** — RICPE/project representations concerning ownership, availability, works, value, maturity and returns.
6. **Publicly supported / regulated project** — where specifically supported by evidence: RIC/tax, tourism/planning, regional incentives, FEDER and other official processes.
7. **Successor operating hotel** — HNT / Canarian Hospitality / MYND Yaiza at the same physical location.

The public question is not “which life is fake?” It is:

> **What was represented to each audience, on what date, by whom, on what claimed title or authority, using which asset perimeter, and how was that representation reconciled with the others?**

### Converging pressure tracks — what mechanisms were acting on the hotel/platform?

- creditor / Concurso;
- Community governance / voting / debt / security;
- property / title;
- access / security / material control;
- hotel operation / customers / staff;
- rescue / financing;
- redevelopment / commercial project;
- regulatory / public-support processes;
- narrative / media / public perception.

Preferred public formulation:

> **Multiple legally distinct tracks converged on the same physical and economic hotel. The recovery inquiry asks whether a decision or act in one track constrained, displaced, pre-empted or supplied the factual premise used in another.**

For each proposed cross-track effect use:

`SOURCE EVENT → ACTOR / AUTHORITY → LEGAL OR ECONOMIC BRIDGE → AFFECTED RIGHT / OPTION → CONSEQUENCE → EVIDENCE STATUS → COUNTERFACTUAL / GAP`

Chronological proximity is not itself the bridge.
