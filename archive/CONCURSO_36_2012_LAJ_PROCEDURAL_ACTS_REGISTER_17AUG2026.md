## LAJ / Judge competence split to preserve

For each event future threads must answer:

1. Did the LAJ have procedural competence to act directly?
2. Was a judicial decision required?
3. Did the LAJ merely implement a signed judicial resolution?
4. Was the event administrative/service handling rather than a formal LAJ act?
5. What remedy existed against the LAJ act?

This classification controls whether an issue belongs to:

- appellate/judicial review;
- LAJ hierarchy / Secretaría de Gobierno;
- court-functioning / inspection;
- or potential judicial-discipline analysis.
