## 1. Non-negotiable rule

A fresh thread must preserve this actor separation at every node:

> **CAM REQUEST / POSITION → AC RECOMMENDATION OR IMPLEMENTATION → JUDGE DECISION OR PROVED OMISSION → CONSEQUENCE**

Never write “the court/AC allowed CAM…” where the sources permit identification of the actual actor. A CAM request is not an AC finding. An AC recommendation is not a judicial finding. An AC implementation act is not automatically a Judge act. Judicial silence is not proved omission without issue + power/duty + verified absence of response + material consequence.

## 8. Judge omission threshold

1. issue was actually before the Judge;
2. Judge had procedural power/duty to act;
3. no responsive judicial act is found after complete search;
4. material consequence is evidenced.
