# Project Sun Rock — Master Proceedings & Institutional Files Register

**Internal knowledge-management register — not a public consolidated case list**  
Cut-off: **20 August 2026**

## Purpose

This register is the internal canonical inventory of identified judicial proceedings, Fiscalía files, professional/deontological files, administrative files, regulatory/supervisory files and other institutional references materially connected to Project Sun Rock / Por Derecho.

It is deliberately **not** a publication instruction. The public website may disclose individual proceedings where relevant to a page, but this register should not automatically be rendered as a single public “all proceedings” index.

## Control rules

1. One legally distinct proceeding/file per row.
2. Do not convert a filing receipt, REGAGE number, technical identifier or correspondence thread into a separate proceeding unless an institution has assigned a distinct file/reference.
3. Appeals are separate rows where they have their own appellate roll/file; otherwise record them as a procedural phase of the underlying matter.
4. Keep `DIRECT`, `CONTEXTUAL`, `SUPERVISION`, `ADMINISTRATIVE`, `REGULATORY`, `TAX`, `REGISTERED_ONLY`, and `TECHNICAL_REFERENCE_NOT_PROCEEDING` distinct.
5. Status must be source-controlled: `OPEN`, `PENDING`, `ARCHIVED`, `APPEALED`, `REFERRED`, `CLOSED`, `UNKNOWN_CURRENT_STATUS`, `REGISTERED_ONLY`, or `TECHNICAL_REFERENCE`.
6. “Not located” never means “does not exist”.
7. New evidence must be checked against the existing row before adding a new row, to avoid duplicates.
8. Public-site propagation is separately gated: reference + status + scope + limitations + privacy/privilege review.

## Website publication rule

The public website should normally expose a proceeding **where it helps explain the substantive page**, not because it exists in this register. Preferred publication pattern:

`relevant issue → exact proceeding/reference → current status → what it does / does not decide → source → invitation to reconcile/respond`.

Avoid a top-level public “all cases against everyone” page. If a future transparency page is useful, it should be a restrained **procedural-reference methodology page**, not a litigation scoreboard.
