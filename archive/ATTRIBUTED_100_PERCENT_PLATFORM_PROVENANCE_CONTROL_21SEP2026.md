## 5. Forward/backward tracing required

Use both directions:

`ORIGINAL RIGHT / ASSET / OPPORTUNITY → DISPLACEMENT / CONTROL → PRE-TITLE COMMERCIAL USE → REPRESENTATION → OPERATOR / INVESTOR / PROFESSIONAL RELIANCE → COMMITMENT / FUNDING / CONTRACT → INCOME / FEE / EQUITY / ASSET / REPUTATIONAL BENEFIT → REINVESTMENT / SUBSTITUTE / LATER OPPORTUNITY → CURRENT HOLDER / CAPACITY`

and:

`LATER ASSET / RELATIONSHIP / REVENUE / INVESTMENT → ACTUAL DECISION INPUTS → RELIED-ON TRACK RECORD / RIGHT / INFORMATION / SECURITY / REPUTATION → SOURCE AND AUTHORITY AT THE TIME → CAUSAL CONTRIBUTION → LAWFUL INDEPENDENT INPUTS`.

A direct cash-transfer gap does not close opportunity, goodwill, track-record, access, mandate, financing or reputational-benefit questions. Equally, chronological sequence alone does not prove causation.
