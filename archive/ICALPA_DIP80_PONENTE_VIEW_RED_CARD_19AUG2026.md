## Purpose

The DIP 80 Second Pair route is now designed first for a ponente. It provides:

1. a 60-second present-state view;
2. three separate instruments: deontological concern, decision readiness and escalation urgency;
3. a protected-interest constellation extending beyond insolvency practice;
4. a red-card candidate attached to the cumulative file state, never to the person;
5. the strongest case against escalation;
6. explicit clearance/downgrade conditions;
7. six finite actions that materially change the file;
8. the existing eleven Second Pair checkpoints as depth on demand;
9. accessible colour + symbol + word coding;
10. a print-ready human decision packet.

## Red-card status

`CANDIDATE — HUMAN CONFIRMATION PENDING`

It is not a breach finding, guilt, credibility assessment, suspension recommendation, suitability determination or ICALPA decision.

Internal Por Derecho threshold only:

- two source-linked hard factors; or
- one hard factor plus three supporting conditions.

This is not a statutory or disciplinary test.

1. certify the official file and status;

4. close act-by-act temporal analysis;
5. reconcile 2022 credit, dation, €400,000 and accounts;

## Non-negotiable safeguards

- red attaches to file state, never name or portrait;
- colour is never the sole signal;
- no guilt/credibility percentage;
- silence is not admission;
- DIP 79 evidence does not enter DIP 80 without human relevance classification;
- context does not replace act, duty, date, knowledge, capacity, causation or professional explanation;
- registered ≠ reviewed ≠ verified ≠ sufficient ≠ culpability;
- every consequential outcome remains human;
- concern resolution receives equal visual status to escalation.

Future work must read this file together with the Second Pair activation and application-standard records before changing the red-card state or implying institutional adoption.
