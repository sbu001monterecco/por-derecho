1. Drive exact date + act type + `36/2012`;

3. Gmail date / subject / attachment search;
4. counsel/procurador sender search;
5. appeal or later act that annexes/quotes it;
6. CGPJ / Fiscalía / AP evidential bundles;
7. court/LAJ certified-index request if still absent.
