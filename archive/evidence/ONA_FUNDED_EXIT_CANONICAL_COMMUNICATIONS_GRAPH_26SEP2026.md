## Rule

Every material email, email thread, professional conversation memorialised contemporaneously in writing, meeting report, call note, message, or transmitted attachment that bears on a material event must be canonically registered and interlinked. A material communication is not merely archived: it must be connected to the proposition(s), event(s), actor(s), proceeding(s), instrument(s), dependencies and contrary evidence it supports or qualifies.

### Required canonical fields
1. Stable evidence ID.
2. Provider/source and immutable provider identifier where available (Gmail message ID, Drive ID, repository path/commit, court reference).
3. Date/time and timezone where available.
4. Sender/author and material recipients/participants.
5. Original subject/title.
6. Thread lineage: parent, forwarded source, reply/continuation, duplicate/mirror status.
7. Native attachments and canonical preservation IDs.
8. Evidence class: primary institutional / signed instrument / contemporaneous professional account / contemporaneous party account / later reconstruction / hearsay-within-communication.
9. Exact propositions supported.
10. Exact limitations / propositions **not** proved.
11. Event IDs and chronology nodes corroborated.
12. Actor/entity IDs.
13. Proceedings and transaction routes implicated.
14. Reciprocal links to corroborating and contradicting evidence.
15. Maturity label where financing/operator/acquisition evidence is involved.
16. Custody state: native, preservation copy, parsed text, PDF mirror, expired-chat-only, or missing.
17. Public/private status and privilege/confidentiality handling.
18. Gap/production action if a referenced source or attachment is missing.

### Anti-inflation / deduplication
A forwarded copy, duplicate mailbox copy, Drive mirror or later PDF export must not be counted as an independent evidential event merely because another copy exists. One canonical evidence node controls; mirrors are custody/provenance children. Distinct commentary added in a forward/reply is a separate evidence node linked to the underlying source.

### Conversation rule
An oral conversation is registered only when supported by a contemporaneous memorialisation, recording/transcript, participant statement, or other identified source. The graph must say **who reports the conversation** and must not transform that report into an institutional finding.

### Reciprocal-link rule
When communication A confirms, qualifies, contradicts, anticipates or explains event B, both nodes must link to each other. No material event page should rely on an email proposition without linking back to its canonical communication node; no canonical communication node should remain orphaned from the events/propositions for which it is material.
