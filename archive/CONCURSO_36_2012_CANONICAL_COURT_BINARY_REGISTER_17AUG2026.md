## Public/private binary-custody boundary

- This repository, including `archive/`, is a publication surface. `REPOSITORY-ONLY`, folder naming and an internal label are not access controls.
- Public Git may carry public-safe analysis, retrieval metadata, hashes and reviewed/redacted derivatives.
- Unredacted court, bank, Registry, notarial, email and personal-data originals belong in an access-controlled evidential vault with immutable export, signature validation and one-file/one-hash custody.
- A Library copy, self-sent analytical bundle or repository manifest does not prove that every underlying sensitive native binary is present in Git or in that bundle.
- Never publish a sensitive binary merely to close a canonical-register row; preserve the private-original → public-derivative crosswalk instead.
