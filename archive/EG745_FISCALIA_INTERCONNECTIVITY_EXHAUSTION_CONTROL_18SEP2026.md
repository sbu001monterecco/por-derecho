## 4. Positive-exhaustion definition

“Exhaust” means **source-backed closure**, not repeated searching until a desired conclusion appears. A gap can close only as:

- **PROVED** — primary/certified source establishes it;
- **DISPROVED** — primary/certified source establishes the contrary;
- **BOUNDED-NOT-LOCATED** — all defined accessible sources have been searched and retrieval routes recorded;
- **AUTHORITY-ONLY** — the remaining record can only be produced by Fiscalía/court/other custodian;
- **CONFLICT/VARIANT** — competing sources preserved and the exact reconciliation step identified.

No gap closes merely because a search returns no hit.
