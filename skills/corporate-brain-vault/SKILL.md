# Corporate Brain Vault

## Goal

Create a source-grounded canonical intake record without altering the source account or pretending a bounded search is exhaustive.

## Workflow

1. State the exact source account/system and scope being acquired.
2. Preserve source identifiers, timestamps, ownership/account origin and native metadata.
3. Preserve attachment/native-file identity before analysis where supported.
4. Create a stable private intake ID.
5. Hash binary evidence. For native cloud documents, record revision identity and create an immutable export before assigning hash-complete status.
6. Reconcile duplicates by bytes/revision/content evidence. Preserve every independent provenance path.
7. Classify people/entities/events/matters only as routing metadata until content review supports the relationship.
8. Link contrary, correcting and later versions rather than replacing them.
9. Update the private provenance register and the public-safe status/gap layer separately.
10. Never place raw private source bodies, private locators, credentials, privileged advice or unnecessary personal data in the public-facing repository.

## Completion states

- GREEN: acquired scope fully enumerated, preserved, provenance-complete and integrity-verified.
- YELLOW: acquired but a material backfill, export/hash or content review remains.
- ORANGE: source access/connection is missing.
- RED: unsafe or not acquired.
