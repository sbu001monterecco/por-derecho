# SUN ROCK / AWESWELL — Daily SWOT + A+ Operating Standard
**Control date:** 29 September 2026
**Status:** standing internal operating standard; public-safe methodology only.

## Objective
Run one disciplined daily scan across past, present and future signals affecting AWESWELL LIMITED / Sun Rock, the capital programme, Playa Blanca / Lanzarote development, institutional relationships, Media & PR, operational resilience and reputation.

The purpose is not to manufacture activity. It is to identify material changes early, preserve them, classify them correctly, and convert them into the smallest useful next action.

## Time horizons
1. **Past / backfill:** close one unresolved historical evidence, governance, relationship, asset, funding, media or institutional gap per run where useful.
2. **Present / live:** inspect the prior 24–72 hours for correspondence, CI/repository state, public announcements, institutional changes, media, financing, counterparties and project dependencies.
3. **Future / forward:** inspect the next 14–30 days for calls, deadlines, filings, financing gates, public decisions, releases, planning dependencies and opportunities.

## Required SWOT output
Classify material signals as **Strength / Weakness / Opportunity / Threat**. Record source/date, factual signal, why it matters, confidence/evidence status, trend, next action and whether the action is safe for autonomous execution.

## Colour state
- 🟢 GREEN — verified/preserved/ready.
- 🟡 AMBER — conditional, incomplete, waiting or dependent.
- 🔴 RED — active risk, contradictory state or prohibited overstatement.
- 🔵 BLUE — opportunity / improvement action.

## A+ rule
A+ means evidence-backed readiness, not a credit rating or claim of perfection. Each run identifies top three A+ gaps, top three opportunities, one low-risk internal action, one owner decision if needed, and one historical gap to close or consciously defer.

## Source order
Primary connected records → official first-party sources → reliable media/professional sources → attributed internal analysis → labelled inference.

## Communications doctrine
One fact base; separate communications lanes:
- Investor relations informs capital.
- Asset PR explains value.
- Litigation/recovery communications protect the record.
- Crisis communications protect trust.
- Public affairs demonstrates local contribution.
- None may impersonate another.

Never use litigation publicity to raise capital. Never use investor conversations to imply validation of litigation claims.

## Safe autonomous actions
Read connected sources; preserve internal snapshots; update internal/private logs and review branches; de-duplicate/classify; retry CI once when the only visible blocker is infrastructure/quota; prepare drafts, agendas and source maps; flag contradictions and stale wording.

## Hold / explicit approval
Do not autonomously merge to production/main, publish externally, send messages, accept commercial terms, spend, file with authorities, change security/permissions, or announce financing/acquisition/planning/operator/public-authority/legal outcomes.

## Daily report
Executive delta → SWOT → A+ gap closure → forward calendar → preservation → escalation.
