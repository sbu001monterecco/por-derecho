## 4. Bottom-up underwriting rule

Institutional economics should be built from verifiable hotel/project assumptions:

`keys/category → occupancy → ADR/RevPAR → revenue → GOP/EBITDA → capex/development cost → comparable/valuation methodology → debt capacity → equity value/downside`

Do not use a headline recovery-perimeter number as a substitute for hotel underwriting.

Historic Sun Park/recovery value remains legally and financially separate from new-money ProjectCo debt service unless a future lawful, documented transaction expressly changes that position.
