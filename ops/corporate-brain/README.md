# A+ Corporate Brain operating model

This directory defines the public-safe operating controls for the Aweswell / Sun Rock Corporate Brain. It does **not** contain private mailbox bodies, private Drive locators, privileged material, credentials, or raw evidential source files.

## Status colours

- 🟢 **GREEN** — deployed and verified for the stated scope.
- 🟡 **YELLOW** — deployed/designed, but backfill, coverage, or verification remains.
- 🟠 **ORANGE** — an external account connection, credential, platform setup, or other dependency is required.
- 🔴 **RED** — not deployed, or not safe to claim complete.

## Architecture

Human decision-maker
→ ChatGPT / Work command layer
→ specialist workflows and red team
→ Corporate Brain / Truth Machine
→ canonical private vault + source graph + repositories
→ Codex engineering/maintenance layer
→ CI, tests, recovery, and deployment verification.

## Source-of-truth split

1. **Private canonical vault:** native/private source custody, immutable captures, hashes, provenance, private analysis.
2. **Repository:** public-safe schemas, hashes, source-safe identifiers, deterministic code, governance, tests, CI, approved derivatives.
3. **ChatGPT / Work:** interactive analysis, orchestration, connected-source work and human decision support.
4. **Codex:** engineering, repeatable maintenance, migration, validation, regression testing, internal tooling and reviewable code changes.
5. **OpenAI Platform / Agents:** future persistent agent runtime when explicitly configured.

## Non-negotiable rules

- A folder, label, repository path or generated summary is not proof of source completeness.
- One evidential object may have multiple provenance paths.
- Duplicates are reconciled by content/revision evidence, not filenames.
- Every material graph edge must be source-backed.
- Contrary and limiting evidence remains linked.
- Unitized analysis does not merge distinct people, entities, assets, estates, proceedings or legal tracks.
- Private/raw evidence is never copied into a public-facing repository merely to make automation easier.
- No agent, script, status file or CI result authorises an external email, filing, publication, transaction or commitment.
- Consequential external action remains human-approved.

## A+ acceptance

A+ means the defined source perimeter is measurable; all acquired sources have provenance; immutable capture is complete for the defined corpus; duplicate handling preserves provenance; evidence/claim/contrary links are queryable; unresolved gaps are explicit; repository and privacy tests pass; backup restore is verified; and agent outputs remain traceable to source.
