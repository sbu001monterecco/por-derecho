## 1. Objective

Strengthen Por Derecho / Project Sun Rock positions and recovery/accountability objectives by improving the **quality, traceability, falsifiability and routability** of each material proposition. The method is designed to support supported positions more effectively while also clearing, narrowing or correcting propositions that fail independent testing.

The standard is: **stronger through verification, not stronger through repetition.**

## 2. Existing controls retained

This adoption does not replace the current project controls. It binds into them:

- source bridge / no evidential upgrade without a bridge;
- actor × capacity × date attribution;
- formal versus real control;
- proceedings distinct but interconnected;
- contrary/adverse evidence visible;
- context-integrity / truth-inversion source-to-use comparison;
- Second Pair of Eyes;
- institutional decision accountability;
- evidence-intelligence source/proposition/retrieval architecture;
- case-interlink and identity controls;
- missing-evidence / decisive-test discipline;
- NEW→OLD and OLD→NEW propagation;
- private/public and external-action boundaries.

## 3. Seven priority deployment lanes

These are review lanes, not findings.

### A. Corporate / registry reality

Apply the register-versus-reality test to material corporate identities, appointments, ownership/control representations, addresses, trading status, professional roles and filing histories. Preserve canonical legal-person identity and exact dates. A filing proves the filing; an independent source is required for the wider reality asserted from it.

**Desired outcome:** a reusable corporate-status packet that distinguishes registered fact, representation, real-world operation/control and open proof.

### B. Formal title / real control / income

Apply the same method to formal title, possession/access, operation, booking/commercial control, bank/payment control, income receipt and beneficial use. Keep each state separately sourced.

**Desired outcome:** identify the smallest records that can prove or defeat each transition rather than relying on the label “owner/operator/controller”.

### C. Context integrity / truth inversion

For every material adverse proposition alleged to depend on selective quotation, compressed context or a portable prior finding, compare:

underlying source → exact context → later use → invited inference → contrary/restored context → actor-specific knowledge → reliance/effect.

**Desired outcome:** isolate literal truth from evidential implication and identify the finite source capable of resolving the dispute.

### D. Cross-proceeding commonality

When similar mechanisms appear across legally distinct proceedings, first record them as shared-attribute signals. Promote them only after an independent source bridge establishes the relevant actor, act, knowledge, use or causal relation.

**Desired outcome:** expose genuine common mechanisms without converting thematic overlap into conspiracy or corroboration.

### E. Money / value / benefit / recovery

Separate offer, valuation, debt, recognised claim, invoice, reported payment, actual debit, recipient credit, ultimate source, beneficial use, loss and recovery. Match numbers to native records where available.

**Desired outcome:** one auditable source-and-use/value chain and a finite list of missing payment/accounting records.

### F. Institutional notice / knowledge / decision

Use distinct states for transmission, registration, routing, access, examination, verification/rejection, adoption, decision, implementation and effect.

**Desired outcome:** prove exactly what each institution/person had, when, and what they actually did with it, without converting institutional possession into personal knowledge.

### G. Competent outcome / asset-recovery route

For each open proposition, identify the body or process capable of obtaining the decisive evidence or granting the relevant remedy. Carry the same verified source pack across lawful routes without collapsing legal competencies.

**Desired outcome:** fewer diffuse requests, more answerable finite requests, and a documented closure/reopen criterion.

## 4. Operational cycle for each lane

1. Select one bounded proposition or failure mode.
2. Freeze current source/registry state.
3. Record the signal without interpretive inflation.
4. Build the source-origin/independence map.
5. Form a falsifiable link hypothesis.
6. Test the formal record against independent reality.
7. Preserve strongest support + strongest contrary/lawful alternative.
8. Set evidence state and, separately, confidence language.
9. Identify the decisive test.
10. Review harm/priority and competence.
11. Where the same failure can recur, assess preventive/detective/corrective controls and residual risk.
12. Assemble one joined review packet.
13. Run Second Pair / independent challenge.
14. Human outcome: clear / keep open / verify / narrow / correct / escalate / refer / preserve-monitor.
15. Propagate the result through all affected chronologies, graphs, proposition records and reader layers.
16. Record the reopen trigger.

## 6. Google Drive / project-memory integration

Google Drive working controls already preserve the anti-fragmentation, source-bridge, proposition, contrary-evidence, current-main and memory-boundary rules. The durable Drive integration record should carry this UK-derived layer as a **method/control update**, not as new case evidence.

Account-level ChatGPT Memory remains a lossy convenience/continuity layer. It must not be cited as evidence or used to override current repository/source records. The durable operational state belongs in current repositories plus the controlled Drive record.

## 7. Acceptance criteria

The integration is useful only if it can demonstrate all of the following:

- a repeated source is recognised as same-origin instead of “new corroboration”;
- a concern can be cleared and the cleared state remains visible;
- a public/official record can be marked under check without being declared false;
- a later correction propagates to every affected derivative;
- the system identifies a smaller decisive test instead of simply producing a longer narrative;
- a competent recipient receives a finite question and evidence pack;
- a cross-proceeding connection never transfers knowledge/intent/liability automatically;
- control effectiveness and residual risk are used to improve process, not score actors;
- a fresh reviewer can understand why the human decision was made and what would reopen it.
