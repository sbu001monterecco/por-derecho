# Limitation and preservation matrix

**Status:** structure established; specialist counsel validation and dates required.

A single “lender-chain limitation date” is unsafe. Create one ledger per actor, cause of action and remedy.

| Field | Required entry |
|---|---|
| Actor | exact legal person |
| Cause/route | contract, Art. 1902, restitution, corporate succession, concursal, registry, criminal civil liability, other |
| Conduct date | supported date/period |
| Damage date | first and continuing damage analysis |
| Knowledge date | fact and responsible-person knowledge |
| Accrual theory | when action could realistically be exercised |
| Limitation/caducity period | historical/current law and transitional rule |
| Interruption event | demand, filing, acknowledgment or other legally effective act |
| Service/proof | exact recipient, date and proof |
| Effect on other actors | no automatic extension; analyse relationship and doctrine |
| Suspension/continuing wrong | only where legally supportable |
| Finality/res judicata | order/judgment, appeal, notification and finality |
| Next preservation date | action owner and deadline |
