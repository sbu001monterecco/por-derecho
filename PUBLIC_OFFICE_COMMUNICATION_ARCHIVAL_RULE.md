# Mandatory public-office communication archival rule

For every material communication from a public office or public authority in the Project Sun Rock / Por Derecho matter, preserve the **complete source communication** in the repository: full email body (including an express record if empty), full text of all substantive official attachments, source/issuer metadata, dates, subject, official references, original filenames, and signature/registration/authentication metadata where present.

A summary, quotation, chronology entry, analysis or website statement must never substitute for the full source.

This rule is prospective **and retroactive**: whenever an older public-office communication is encountered and only a summary is currently preserved, treat the missing full-source record as an ingestion gap and close it.

The controlling protocol is:

`archive/PUBLIC_OFFICE_COMMUNICATION_FULL_TEXT_ARCHIVAL_PROTOCOL_20AUG2026.md`
