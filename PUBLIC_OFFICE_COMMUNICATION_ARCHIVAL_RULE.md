# Mandatory public-office communication custody and publication rule

For every material communication from a public office or public authority in the Project Sun Rock / Por Derecho matter, preserve the **complete source communication in an access-controlled evidence layer**: full email body, substantive attachments, issuer/source metadata, dates, subject, official references, original filenames, signature/registration/authentication metadata, and the native binary or a verified custody locator where available.

A summary, quotation, chronology entry, analysis or website statement must never substitute for the complete controlled source.

## Public-repository boundary

The public GitHub repository is a publication layer, not the sole primary-custody layer. Public derivatives must redact data that are unnecessary to the institutional proposition, including private email addresses, street addresses, telephone numbers, signatures, document-verification credentials and other personal identifiers.

Retain in the public derivative:

- issuing institution and office;
- date and official reference;
- subject and procedural context;
- source status and custody limitation;
- complete substantive propositions where lawful and necessary;
- a hash or private custody locator when available.

A private repository may hold the full source only where access controls, privilege, secrecy, data-protection and evidential requirements are satisfied.

This rule is prospective and retroactive. When an older communication is represented only by a summary, close the source gap. When an unredacted personal-data copy is found in the public layer, replace the current public version with a redacted derivative and record that the native/full source belongs in private custody.
