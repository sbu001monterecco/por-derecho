# Optional asynchronous clarification email protocol

**Not an authorisation to send email.**

Subject convention: `Clarification request · <CLAR-ID> · <short topic>`

Body must contain:
- stable CLAR ID;
- one neutral proposition/question;
- A/B/C/D definitions;
- invitation to reply with a letter plus free text, or free text only;
- statement that D/uncertainty is acceptable;
- request not to search memory into certainty: distinguish recollection from documents;
- no assertion that silence means agreement.

On ingestion, preserve original email/thread locator privately, create a source-attributed answer object, and run contradiction/source checks. Email is transport only; GitHub registry controls state and private source material remains in appropriate restricted custody.
