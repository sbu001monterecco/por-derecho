# Continuity governance

This directory contains machine-readable controls for continuity, preservation, traceability, supersession and release state.

## Classification model
- **SOURCE_FACT** — what a source actually says or records.
- **PARTY_POSITION** — what an identified actor alleges, argues or instructs.
- **ANALYTICAL_INFERENCE** — a project conclusion drawn from sources.
- **ADJUDICATED_OFFICIAL_STATUS** — what a competent authority has actually decided or officially recorded.

Do not silently promote one class into another.

## Evidence lifecycle
`PRIVATE ORIGINAL → INTAKE/CUSTODY RECORD → WORKING DERIVATIVE → ANALYSIS → PUBLIC-SAFE DERIVATIVE → RELEASE MANIFEST → DEPLOYMENT RECEIPT → LIVE READBACK`

## Green model
- **SOURCE GREEN:** source preserved, identity/custody known, duplicates controlled.
- **ANALYSIS GREEN:** proposition mapped to source, limits and contrary evidence.
- **REPOSITORY GREEN:** approved change merged and read back.
- **PUBLICATION GREEN:** exact approved artifact deployed and independently read back.

Only all four together justify **FULL GREEN**. Evidence completeness remains separate.
