## 3. Recursive method

`observe → manifest → compare → classify → traverse dependencies → adversarial review → reconcile → exact-head verify → deploy if applicable → live readback → new envelope → recurse until closure`

Observe = retrieve source/provenance, not only summaries.  
Manifest = identify who said/did what, when, in what capacity and through what source.  
Compare = put competing versions, earlier/later sources and related records together.  
Classify = distinguish fact, primary-source content, official outcome, attributed allegation, inference, hypothesis, contrary/adverse evidence, unresolved proof and superseded/corrected proposition.  
Traverse dependencies = follow connected actors, assets, proceedings, financing, communications, decisions and consequences.  
Adversarial review = test strongest genuine contrary evidence and plausible lawful alternative.  
Reconcile = update one knowledge architecture rather than preserve contradictory parallel versions.  
Exact-head verify = confirm current implementation state before relying on it.  
Recurse = materially new evidence may reopen an earlier conclusion.
