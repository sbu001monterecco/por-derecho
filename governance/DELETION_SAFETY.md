# Deletion-safety gate

**Control:** PD-DELETION-SAFETY-20261001-01  
**Current state:** 🔴 HOLD

A conversation/workstream is safe to delete only when a clean-room continuation can answer all of the following from preserved systems without relying on chat memory:

- [ ] Current controlling thesis.
- [ ] Most recent material change.
- [ ] Current party position for every material corrected premise.
- [ ] Superseded wording/analysis.
- [ ] Native/source custody locators.
- [ ] Private/public-safe/do-not-publish classification.
- [ ] Current GitHub and GitLab canonical/parity state.
- [ ] Exact release deployed on each host.
- [ ] Live content read back after deployment.
- [ ] Remaining P0/P1 gaps.
- [ ] Propositions that must never be inferred from the record.
- [ ] Contrary/adverse sources preserved.
- [ ] Mirrors prevented from counting as independent corroboration.
- [ ] Controlling corrections propagated to canonical masters and relevant public derivatives.
- [ ] Independent continuity copy outside the canonical repository.
