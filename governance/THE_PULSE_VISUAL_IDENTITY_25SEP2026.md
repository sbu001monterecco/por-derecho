# The Pulse / El Pulso de la Prueba — visual and evidential control

**Control:** PD-PULSE-20260925-01  
**Date:** 25 September 2026  
**Status:** owner-directed public visual identity and operational-status symbol

## Purpose

The Pulse is a recurring Por Derecho visual for source contact and evidential freshness. The core question is: **what does the underlying record actually say — now?**

The symbol consists of a fingertip, an abstract wrist/pulse point, one gold contact point and a short signal. The contact point represents contact with the primary record.

## Relationship to existing method

- Second Pair of Eyes — look again.
- The Pulse — make contact with the primary record and establish current evidential state.
- Truth Machine — test a proposition against identified evidence.
- Truth Delta — record what changed after review.
- Case Control Room / Situation Room — monitor the whole system state.

## Five checks

1. Source.
2. Current evidential state and limits.
3. Source lineage / independence.
4. Support, qualification or contradiction.
5. Downstream adoption / practical effect.

## Mandatory boundary

This is a forensic metaphor, not a physiological lie detector. The visual must never be used to infer fear, truthfulness, intent, credibility, criminality, guilt or liability from a human pulse, handshake or gesture.

The mark never upgrades evidential status by itself. Every displayed pulse state must remain source-bound, dated, and subject to the existing human review and correction controls.
