# Attribution map

## Core publication distinction

1. **Documented court fact** — use only what court/primary record says.
2. **Gil Marer / claimant-side stated factual position** — expressly attributed as such.
3. **Reasonable evidential inference** — identify source chain and uncertainty.
4. **Allegation** — clearly labelled and actor-specific.
5. **Investigative hypothesis** — not a finding; list evidence required to confirm/disprove.
