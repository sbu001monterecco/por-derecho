## 4. Asset classification

A hotel finca is simultaneously:

- a registered private title compartment;

- a node inside a unitary hotel operation;

## 7. Criminal-law discipline

- estafa procesal: exact procedural fraud, judicial error, resolution and economic prejudice;
- conspiracy/proposition: agreement/invitation and resolution concerning a specified offence;
- enablement: translate into co-authorship, instrumentality, inducement, necessary cooperation, complicity or autonomous later offence;
- encubrimiento: post-offence non-participant category, not a catch-all for an alleged original participant;
- fraude concursal: identify the exact candidate offence/act instead of using an omnibus label.
